# 🍽️ KarveMess – Smart Mess Management System

KarveMess is a **full-stack web application** designed to digitalize and streamline mess (canteen) operations.  
It helps manage daily food menus, subscriptions, users, and chefs efficiently, reducing manual effort and improving transparency.

Built using the **MERN Stack**, the project focuses on real-world backend logic, role-based access, and scalable architecture.

---

## 🚀 Features

### 👤 User Features
- View daily food menu

### 👨‍🍳 Chef Features
- Chef authentication (Register / Login)
- Add, update, and delete food items
- Manage menus based on weekdays
- View subscribers for food items
